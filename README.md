# IRINS Multi-Institute Scraper and Analysis

This repository contains a collection of modular Python scripts designed to extract, process, and analyze academic data from the *IRINS (Indian Research Information Network System)* portals of various Indian institutes.  
The workflow automates fetching institute information, scraping faculty profiles, updating experience and geolocation data, predicting academic designations, and generating analytical visualizations.

---

## Output Structure

- **outputs/ml-outputs/** — Stores model predictions and outputs from predict_designation.py  
- **outputs/analysis/** — Stores data summaries, visualizations, and metrics generated by analysis.py  
- **outputs/output-maps/** — Contains maps showing spatial density and distribution analyses  

---

## Scripts Overview

### institute_url_scraper.py
Fetches institute data from the *IRINS portal*, filters by specific categories (IITs, NITs, IIMs, IISERs, R&D Institutions, Other INIs), and stores the results in a fresh SQLite database.

---

### profile_scraper.py
Extracts faculty and researcher data from IRINS portals across multiple Indian institutes.  
Reads institute URLs from a SQLite database, crawls departmental and individual profile pages, and stores structured data into institute-specific SQLite databases.

---

### update_experience.py
Updates faculty experience across all profile databases.

*Features:*
- Deduplicates identical experience entries  
- Computes total experience per faculty  
- Replaces zero-year experiences with NULL  
- Provides a safe, logged, and modular workflow  

---

### update_geolocation.py
Updates *geolocation data* using the OpenCage API.  
Adds fields such as country, state, city, latitude, longitude, and full_address to the qualification table in each *_profiles.db database.

---

### predict_designation.py
Implements a *Random Forest Classifier* for predicting academic career levels.  
Includes:
- Text embeddings  
- Interaction features  
- Balanced sampling techniques  

Outputs stored in: outputs/ml-outputs/

---

### merge_data.py
Builds a unified *Researcher Career Flow Database* by filtering institutes by organization type and aggregating researcher career data across multiple sources.

---

### researcher_flows.py
Aggregates data from multiple *_profiles.db files (one per institute) and merges them with IRINS institute coordinates to create a *comprehensive SQLite database* for career flow analysis.

---

### analysis.py
Performs detailed data analysis, including pattern detection, statistical summaries, and visualization generation.

Outputs stored in: outputs/analysis/  
Maps stored in: outputs/output-maps/
